# Data Dictionary

Source: Backblaze Hard Drive Test Data (Drive Stats), https://www.backblaze.com/cloud-storage/resources/hard-drive-test-data.
Data provided by Backblaze; cited as the source per its usage terms.

## Raw files (Backblaze daily CSVs)

- One CSV per day named `YYYY-MM-DD.csv`, inside `data_<Qn>_<YYYY>/` in each quarterly ZIP. One row = one drive on one day.
- **Observed scale of the profiled quarter (Q2 2026,** from `results/profiling/Q2_2026/summary.json`**):**
  31,968,003 rows; 91 days (2026-04-01 to 2026-06-30); 359,101 distinct serial numbers; 81 distinct model strings;
  1,522 failure rows.
- **Schema versions in scope:** 193 columns for Q3 2023–Q1 2024. 197 columns from Q2 2024 on, which adds `smart_211_*` and `smart_212_*`.
- **Null rates** below are computed over all 31,968,003 rows of Q2 2026, generated by
  `scripts/build_raw_dictionary.py` from `results/profiling/Q2_2026/column_profile.csv`. Empty CSV fields count as null.
- **SMART columns:** each attribute has a `_normalized` column (vendor-scaled health value) and a `_raw` column (raw counter).
  Attribute meanings are the conventional ATA names. Raw encodings differ by manufacturer; for example, Seagate packs
  SMART 1/7 raw values, so they are not comparable across vendors.
- Null rates by manufacturer for every SMART raw column: `results/profiling/Q2_2026/smart_null_rate_by_mfr.csv`.

## Gold

### `backblaze.gold.drive_lifetimes` — one row per drive (all drives; filter `is_data_drive`)

| Column | Type | Meaning |
|---|---|---|
| `serial_number` | STRING | Drive identifier (unique) |
| `model`, `model_short`, `manufacturer` | STRING | Most frequent normalized model for the drive |
| `capacity_bytes`, `is_data_drive` | BIGINT, BOOLEAN | As in silver |
| `first_date`, `last_date` | DATE | First / last observed day in the window |
| `n_obs_days` | BIGINT | Observed drive-days (rows); sums to silver row count |
| `observed_days` | INT | Calendar span `last_date - first_date + 1` (≥ `n_obs_days`; gaps are not imputed) |
| `failed` | INT | 1 iff the last observed row has `failure = 1` |
| `failure_date` | DATE | `last_date` for failed drives, else null |
| `censored` | INT | `1 - failed` (right-censored) |
| `event` | STRING | `failed`, `censored_window_end` (running on the last window day), `censored_left_fleet` |
| `left_truncated` | INT | 1 if first seen on the window's first day (already in service before the window) |
| `poh_first`, `poh_last` | BIGINT | Wraparound-corrected SMART 9 power-on hours at the first / last day with a non-null reading (wrap detected via SMART 240; `reliability.age`) |
| `entry_age_days` | DOUBLE | Age on `first_date`: `poh_first / 24` back-dated by the days between `first_date` and the first non-null reading (delayed-entry time for survival) |
| `exit_age_days` | DOUBLE | `entry_age_days + observed_days`: age at failure or censoring |
| `age_ok` | INT | 1 if a SMART 9 reading exists, entry age is ≥ 0 and ≤ 15 years, and readings are non-decreasing; ages are null in analyses otherwise |
| `n_failure_rows`, `reappeared_after_failure` | INT | Failure-semantics audit (0 reappearances so far) |
| `n_models`, `n_capacities` | INT | Distinct values seen for the drive (audit) |
| `window_start`, `window_end` | DATE | Data window used for this build |
