# Data Dictionary

Source: Backblaze Hard Drive Test Data (Drive Stats), https://www.backblaze.com/cloud-storage/resources/hard-drive-test-data.
Data provided by Backblaze; cited as the source per its usage terms.

## Raw files (Backblaze daily CSVs)

- One CSV per day named `YYYY-MM-DD.csv`, inside `data_<Qn>_<YYYY>/` in each quarterly ZIP. One row = one drive on one day.
- **Observed scale of the profiled quarter (Q2 2026,** from `results/profiling/Q2_2026/summary.json`**):**
  31,968,003 rows; 91 days (2026-04-01 to 2026-06-30); 359,101 distinct serial numbers; 81 distinct model strings;
  1,522 failure rows.
- **Schema versions in scope:** 193 columns for Q3 2023–Q1 2024. 197 columns from Q2 2024 on, which adds `smart_211_*` and `smart_212_*`.
- **Null rates** below are computed over all 31,968,003 rows of Q2 2026, generated by
  `scripts/build_raw_dictionary.py` from `results/profiling/Q2_2026/column_profile.csv`. Empty CSV fields count as null.
- **SMART columns:** each attribute has a `_normalized` column (vendor-scaled health value) and a `_raw` column (raw counter).
  Attribute meanings are the conventional ATA names. Raw encodings differ by manufacturer; for example, Seagate packs
  SMART 1/7 raw values, so they are not comparable across vendors.
- Null rates by manufacturer for every SMART raw column: `results/profiling/Q2_2026/smart_null_rate_by_mfr.csv`.
